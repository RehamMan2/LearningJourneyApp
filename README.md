
# Learning Journey App 📚

An iOS application designed to help users build consistent learning habits and track their progress.

## Overview

LearningApp helps users set learning goals, track daily activities, and maintain learning streaks.

## Features

- Set personalized learning goals
- Track daily learning progress
- View learning history in a calendar
- Maintain learning streaks
- Use Freeze Days to protect streaks
- Update learning goals

## Technologies

- Swift
- SwiftUI
- MVVM Architecture
- Xcode

## Architecture

The application follows the MVVM
(Model-View-ViewModel) design pattern.

- Model: Manages application data
- View: Displays the user interface
- ViewModel: Handles application logic

## Screens

- Onboarding
- Activity
- Calendar
- Set Goal
- Update Goal

## Getting Started

1. Clone the repository.
2. Open the project in Xcode.
3. Select an iOS Simulator.
4. Build and run the application.
